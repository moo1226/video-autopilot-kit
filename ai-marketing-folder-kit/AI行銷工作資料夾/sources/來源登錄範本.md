# 來源登錄範本

> 用途：登錄文案中會引用的**公開資料**，讓每個事實都能追溯。
> 規則：只登錄公開來源。內部資料、個資一律不得登錄（見 `rules/資料使用規則.md`）。

---

## 一、欄位說明

| 欄位 | 填寫說明 |
|---|---|
| 編號 | S-001、S-002……依序編號，文案中用此編號對照 |
| 來源名稱 | 網頁或文件標題 |
| 網址 | 完整網址 |
| 發布者 | 發布單位名稱（官方機構、考試主辦單位等） |
| 來源類型 | 官方／政府／學術／媒體／其他 |
| 發布或更新日期 | 網頁標示的日期；沒有就寫「未標示」 |
| 取得日期 | 你查閱的日期（西元） |
| 摘錄重點 | 只寫要引用的那一句或那個數字 |
| 可信度 | 高（官方第一手）／中（可靠二手）／低（需再查證） |
| 可引用範圍 | 可直接引用／僅供參考／不可對外引用 |
| 備註 | 授權限制、需定期複查等 |

## 四、登錄檢查

- [ ] 每筆都有網址與取得日期
- [ ] 摘錄重點只寫要引用的內容，沒有整段複製
- [ ] 可信度為「低」的資料，沒有直接用在文案中
- [ ] 沒有登錄任何內部資料或個資
