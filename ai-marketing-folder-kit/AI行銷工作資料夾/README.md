# AI 行銷工作資料夾｜操作說明

> 本套件為**練習用示範系統**，情境為「成人語言課程行銷」。
> 所有機構、課程、日期、價格、人員皆為【虛構示例】，不含任何真實機構或公司內部資料。

---

## 一、這套資料夾能做什麼

讓你用 AI（Claude 或 ChatGPT）產出課程行銷文案時，做到四件事：

1. **來源可追溯**：每個事實都知道從哪裡來。
2. **規則一致**：AI 每次都依同一套指引工作，不亂編數字。
3. **格式固定**：文案依範本產出，SEO 欄位不漏。
4. **可交接**：換人、換對話也能接著做。

---

## 二、資料夾結構

```
AI行銷工作資料夾/
├── README.md                    ← 你正在看的這份
├── sources/                     ← ① 來源：公開資料登錄
│   └── 來源登錄範本.md
├── rules/                       ← ② 規則：AI 該怎麼做、不能做什麼
│   ├── Claude專案指引.md
│   ├── ChatGPT-Projects指引.md
│   └── 資料使用規則.md
├── templates/                   ← ③ 範本：文案格式與驗收標準
│   ├── 課程SEO文案範本.md
│   └── QA驗收清單.md
└── outputs/                     ← ④ 成果：草稿、交接、定稿
    ├── 交接紀錄範本.md
    ├── drafts/
    │   └── 示例草稿_職場英語會話B1.md
    └── deliverables/
        └── 說明.md
```

## 三、3 步驟上手

### 步驟 1：設定 AI 專案（只需做一次）

| 你用的工具 | 做法 |
|---|---|
| Claude | 建立新 Project → 將 `rules/Claude專案指引.md` 全文貼到「專案指示（Project instructions）」→ 把 `rules/資料使用規則.md`、`templates/` 內兩份檔案上傳到專案知識庫 |
| ChatGPT | 建立新 Project → 將 `rules/ChatGPT-Projects指引.md` 全文貼到「Instructions」→ 同樣上傳上述檔案 |

> 提醒：各平台介面名稱可能隨版本調整，以你畫面上實際顯示為準。

### 步驟 2：登錄來源 → 產出草稿

1. 打開 `sources/來源登錄範本.md`，把要引用的**公開資料**逐筆填入（例如 CEFR 官方說明、考試官方網站）。
2. 在 AI 專案中輸入，例如：
   > 請依「課程SEO文案範本」，為以下課程寫一份草稿。課程資訊：〔貼上課程資料〕。可引用來源：〔貼上來源登錄表〕。
3. 將 AI 產出存到 `outputs/drafts/`，檔名建議：`日期_課程名_v1.md`。

### 步驟 3：驗收 → 定稿 → 交接

1. 用 `templates/QA驗收清單.md` 逐項勾選，不合格就請 AI 修改。
2. 全部通過後，移到 `outputs/deliverables/`，檔名改成 `_final`。
3. 工作中斷或要換人時，填寫 `outputs/交接紀錄範本.md`。

## 四、工作流程圖（文字版）

```
公開來源 ──登錄──▶ sources/
                      │
rules/ ──設定成 AI 專案指引──┐
                      ▼      ▼
templates/ ──▶  AI 產出草稿 ──▶ outputs/drafts/
                                  │
                       QA驗收清單 ─┤ 不通過 → 退回修改
                                  ▼ 通過
                        outputs/deliverables/
                                  │
                        交接紀錄（需要時）
```

---

## 五、安全與使用原則（摘要）

- 只放**公開資料**或**明確標示的虛構資料**。
- 不放學員個資、內部營收、未公開價格、合約、會議紀錄。
- AI 產出的數字、日期、價格一律要對照來源，不能直接發布。
- 詳細規則請看 `rules/資料使用規則.md`。

## 六、檔名與版本規則

| 類型 | 命名格式 | 範例 |
|---|---|---|
| 草稿 | `YYYYMMDD_課程名_v序號.md` | `20990105_職場英語會話B1_v1.md` |
| 定稿 | `YYYYMMDD_課程名_final.md` | `20990110_職場英語會話B1_final.md` |
| 交接 | `YYYYMMDD_交接_主題.md` | `20990110_交接_春季招生文案.md` |

> 範例日期 2099 年為虛構，實際使用時改成當天日期。
