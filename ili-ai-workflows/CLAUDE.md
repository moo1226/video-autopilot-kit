# ILI AI Workflows

## 這是什麼專案
這是中國文化大學推廣教育部國際語文中心（ILI）英語組的工作流程管理專案。
使用 Claude Code 的 Skills 功能，把重複性的工作（例如撰寫課程頁文案）整理成
可重複使用的標準流程，減少每次從零開始的時間。

## 使用者背景
- 身分：ILI 英語組資深專案／課務／行銷承辦人員（原華語中心資深承辦）
- 工作範圍：成人語言課程、招生行銷、課務行政、專案管理、跨部門協調、
  外籍教師溝通、數據分析、SEO／SEM／GEO／AIO、多語文案與公告撰寫
- 常用語言：繁體中文、英文、日文、韓文
- 常用工具：Notion、Canva、Google Workspace、Excel、LINE@、Threads、Meta
- **沒有程式或 GitHub 背景**，說明時請用白話文，不要假設懂技術術語

## 目前階段
**第一階段：基礎架構**
- 不使用 GitHub Actions、API 或複雜自動化
- 不建立或要求提供 API key
- 不公開 repository
- 每個 Skill 都是「純文字工作流程指引」，由使用者手動觸發，不做自動化串接

## 可用 Skills
| Skill 名稱 | 用途 | 狀態 |
|---|---|---|
| course-page | 協助撰寫成人英語課程外網文案（課程名稱、副標、介紹、FAQ 等），含 SEO/GEO/AIO/AEO/Mobile-first/CTA 優化 | 已建立 |

## 通用規則（所有 Skills 都要遵守）
1. **不得捏造資訊**：任何未知的課程資訊（例如師資、確切開課時間、價格），
   一律標示「請提供」或「[待確認]」，不得自行編造。
2. **繁體中文（台灣用語）為主**，除非使用者要求其他語言。
3. **先給結論與可直接使用的成品**，不要長篇鋪陳。
4. 專有名詞使用官方正確名稱（CEFR 僅用 A1-C2、TOEIC/TOEFL iBT/IELTS 等
   須用官方全名與正確計分制）。
5. 每次修改內容時，需標明「哪裡改了、為什麼改」。
